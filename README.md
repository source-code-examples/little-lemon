# 🍋 Little Lemon Restaurant Web App

A responsive and accessible single-page application for the fictional Little Lemon restaurant. Built with **React** as part of the **Meta Front-End Developer Capstone**, this project demonstrates modern web development practices including semantic HTML, ARIA accessibility, client-side routing, and comprehensive form validation and component-based architecture.

---

## Key Features

- **Responsive Design** – Optimized for desktop, tablet, and mobile devices
- **Client-Side Routing** – Seamless navigation using React Router
- **Form Validation** – Robust booking form with validation logic
- **Accessibility** – Designed with ARIA roles and semantic HTML
- **Reusable Components** – Modular and maintainable code structure
- **Modern Tooling** – Built with React, JSX, and CSS Modules

---
